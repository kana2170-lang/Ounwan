# 오운완 — 인터뷰용 프로토타입

내 몸의 변화를 읽고, 다음 운동을 정하다.

서비스 이해도와 사용 흐름을 확인하기 위한 인터뷰용 시안입니다. 체험 인물은 현경이며 모든 신체 수치, 운동 기록, 추천은 가상 예시입니다.

## 체험

서비스 소개 → 내 목표 설정 → 오늘 → 운동 기록 → 몸의 변화 → 주간 리포트 → 내 프로필 → 커뮤니티 순서로 살펴볼 수 있습니다. 스토어는 향후 확장 구상입니다.

실제 계정, 인바디 연동, 사진 업로드, 운동 분석, 외부 공유, 결제 기능은 제공하지 않습니다. 인터뷰 응답이나 신체 정보를 서버에 수집하지 않습니다. 일부 화면 선택 상태는 브라우저에 저장될 수 있습니다.

## 배포

빌드 없이 index.html을 제공하는 정적 사이트입니다. GitHub Pages에서 main 브랜치의 루트 폴더를 게시 대상으로 설정합니다.

## 인터뷰 질문

1. 첫 화면만 보고 어떤 서비스라고 이해했나요?
2. 자신의 운동 경험을 선택하고 운동 기록을 마쳐보세요. 어디에서 막혔나요?
3. 다음 주에도 다시 열어볼 화면은 어디인가요? 이유는 무엇인가요?
4. 공개하고 싶은 기록과 공개하고 싶지 않은 기록은 무엇인가요?
5. 현재 사용하는 방법보다 더 나은 점과 부족한 점은 무엇인가요?
